3.2 通用数据分析

通用数据分析功能适用于各类结构化和非结构化数据的处理和分析，帮助用户从海量数据中挖掘价值。

3.2.1 文件数据清洗与结构化​

Jenius提供强大的数据清洗和结构化能力，支持多种数据格式的导入和处理：

功能
  • 多格式文件导入：支持导入Docx、CSV、Excel、JSON、XML、PDF、MD等多种格式的文件数据。
  • 数据质量检查：自动检测数据中的缺失值、异常值、重复值等问题。
  • 智能数据清洗：提供基于规则和AI的自动数据清洗功能，包括缺失值填充、异常值处理、数据标准化等。
  • 数据类型识别与转换：自动识别数据类型并进行必要的转换，如日期格式统一、数值单位标准化等。
  • 非结构化数据结构化：将文本、图片等非结构化数据转换为结构化格式，便于后续分析。
使用示例1：
请帮我处理这份包含销售数据的Excel文件，清洗其中的异常值和缺失值，并将结果保存为结构化的CSV格式。

3.2.2 数据趋势与规律分析​

Jenius能够帮助用户发现数据中的趋势和规律，提供深度洞察：

功能
  • 时间序列分析：识别数据随时间变化的趋势、季节性和周期性模式。
  • 相关性分析：分析不同变量之间的相关性，发现潜在的关联关系。
  • 聚类分析：基于数据特征对样本进行自动分类，识别不同的数据群体。
  • 异常检测：识别数据中的异常点和异常模式，提供可能的解释。
  • 预测分析：基于历史数据构建预测模型，对未来趋势进行预测。
使用示例1：
请分析过去5年的月度销售数据，识别其中的季节性模式，并预测未来3个月的销售额。
