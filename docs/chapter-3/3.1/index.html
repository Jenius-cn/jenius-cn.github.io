3.1 财报分析

财报分析是Jenius的核心功能之一，它能够帮助投资者和分析师快速解析各类财务报告，提取关键数据并进行深度分析。

3.1.1 股票数据解析​

Jenius智能体可实时获取并解析股票市场数据，包括但不限于以下功能：

功能
  • 实时行情监控：获取全球主要股票市场的实时行情数据，包括开盘价、收盘价、最高价、最低价、成交量等关键指标。
  • 历史数据回溯：支持查询并分析任意时间段内的股票历史交易数据，便于进行趋势分析和模式识别。
  • 技术指标计算：自动计算常用技术分析指标，如移动平均线(MA)、相对强弱指数(RSI)、布林带(BOLL)等。
  • 基本面数据整合：将股票的基本面数据（如市盈率、市净率、营收增长等）与市场表现数据进行关联分析。
  • 异常波动检测：智能识别股票价格和交易量的异常波动情况，并提供可能的原因分析。
使用示例1：
请帮我分析过去30天内腾讯控股(0700.HK)的股价走势，并计算其10日和20日移动平均线，识别可能的买入/卖出信号。

3.1.2 年报数据解析​

年报数据解析功能专注于对企业年度财务报告的智能处理：

功能
  • 财报结构识别：自动识别和解析年报的各个部分，如资产负债表、利润表、现金流量表等。
  • 关键指标提取：快速提取年报中的关键财务指标，如营收、净利润、毛利率、净利率等。
  • 多期对比分析：支持对多家公司或同一公司多个年度的财务数据进行对比分析。
  • 财务比率计算：自动计算各类财务比率，如偿债能力比率、运营能力比率、盈利能力比率等。
  • 风险预警：基于财务数据识别潜在的财务风险，并提供风险预警。
使用示例1：
请帮我解析阿里巴巴2023年年度报告，提取其营收、净利润、毛利率等关键指标，并与2022年数据进行对比分析。
